How to make GNS3 reachable

Option 1 — Same network (recommended for thesis)
Run GNS3 on a laptop on the same LAN as the server. Enter that laptop's LAN IP here.

Option 2 — Port forwarding
Forward port 3080 (REST API) and the console ports (e.g. 5000–5100) from your router to your GNS3 machine. Enter your public IP here.

Note on console ports
GNS3 assigns telnet ports like 5001, 5002 … for each device. These must also be reachable on the same IP you enter above. Check which ports are in use in GNS3 → Edit → Preferences → Console.
